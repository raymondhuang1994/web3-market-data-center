# 数据可获取性、颗粒度与首版接入方案

文档日期：2026-09-15；样本主要取得于 2026-09-14 夜间（北京时间）。状态：评审资料，尚未接入生产或取得新增服务授权。

本表回答“可以读到什么、细到什么程度、哪些尚未验证”，不把接口成功或插件已连接等同于可公开上线。只覆盖 [PRD](PRD.md) 确定的四组专题。静态网站实际会向浏览器提供机器可读的快照，因此公开使用核验也覆盖这些派生JSON，而不只是网页文字显示。

## 1. 当前判断

**具备制作高完成度网页的技术基础，但现阶段不能承诺全部数据在免费且公开展示条件下已就绪。**成功样本已覆盖 CEX 历史成交、稳定币、Robinhood 部分链上指标、Hyperliquid 部分历史，以及新增 DEX 份额的官方历史数据。其余页面不少只有结构或目录通过验证。

首版优先处理：来源可用、定义明确且能持续更新的核心图表；同时完整保留未接通的内部视图。原站接口可作为对照和历史候选，生产方案优先采用已核验适用于本项目的官方来源。不能为追求覆盖率把不同市场、不同产品或不同统计范围拼成同一指标。

证据标签：

- **响应已实测**：取得数据样本，非生产稳定性承诺。
- **页面 / 脚本已确认**：看到结构或请求方式，尚未验证相应数据序列。
- **官方文档确认**：有明确文档，未完成目标环境调用验收。
- **公开使用待确认**：本次没有足够依据认定该公开业务网站的使用范围已获许可。

## 3. DEX 份额的关键判断

官方免费现货接口可以取得协议层面的日历史，有能力支撑完整日、7日、30日的份额计算。相比单纯插件快照，这对高管和营销团队更有用：能区分规模变化与份额变化，并检查跨期可比性。

但本轮顶层 `total24h`、逐协议 `total24h` 合计和昨日历史总量明显不一致。三个抽样日期的同日 breakdown 合计与对应日总量一致，因此推荐用同一完整日 breakdown 自算分子分母。不能混用不同字段形成看似精确的饼图。

免费 OI 可以用于单独的持仓概念，但不是永续成交份额的替代。本轮不新增一个 OI 市场份额栏目以填补成交数据缺口。完整规则及官方文档见 [DEX审计](research/dex-hyperliquid-audit.md)。

DefiLlama [条款](https://defillama.com/terms) 对未经许可再发布与商业使用有限制。拟用于公开业务网站时，需确认适用许可，或由用户批准另选来源 / 明确样本范围；只加署名不等于已解决。不会未经授权联系供应商。

| --- | --- | --- | --- |
| `perpDexs` | 默认市场 + 10个命名dex | 动态枚举默认 / HIP-3 范围 | 不是10个市场全部数据均已验收 |
| 默认 `metaAndAssetCtxs` | 234条元数据与context | 合约级价格、名义量、OI、funding | 不等于234个活跃交易对 |
| `dex=xyz` contexts | 120条 | 验证HIP-3逐合约颗粒度 | 不是股票代币实际发行规模 |
| BTC `candleSnapshot` 1d | 4根，其中最后一根尚未闭合 | OHLC、基础币量、笔数与开闭时间 | 不能拿基础量×单个价格当实际日美元成交量 |
| BTC `fundingHistory` | 两日48条 | 小时已结算资金费率历史 | 不能按CEX默认8h周期显示 |
| 完整多年OI历史 | 当前context不提供；S3官方说明请求者付费 | 自接入日起保存快照；历史候选另评估 | 不承诺无成本回填多年OI |

见 [Hyperliquid 官方永续接口](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint/perpetuals)、[历史数据说明](https://hyperliquid.gitbook.io/hyperliquid-docs/historical-data)。

这些来源提高原有 Hyperliquid 视图的实现可能性，但不支持自动添加用户、清算、资金流等尚未获批且无完整依据的新指标。

## 6. 免费约束下的执行建议

1. 先固定原有内部组件和指标家族，避免仅按路由计算覆盖率。
2. 优先核验 CEX 历史成交、稳定币、DEX 现货份额和 Hyperliquid 已读数据的公开使用条件与持续更新链路。
3. 对 CEX 高阶历史、Robinhood / Hyperliquid 其余子图逐项取样和查口径；现有成功样本不能代表其全部可用。
4. 原站研究评分和缺少可比参考价的套利保留为待确认；不复制作者结论或不可靠数字。
5. 不先买任何套餐。若免费来源不能达到PRD建议的数据覆盖门槛，给用户具体缺项和代价，再决定。

首版验收分别报告结构完成率、真实数据覆盖率、公开可用状态、最近成功运行时间和上游数据日期。当前处于调研阶段，这些生产指标尚未达成。
