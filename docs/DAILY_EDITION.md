# 每日 09:00 数据与 AI 解读

用户于 2026-09-15 批准：免费数据来源，每天包括周末及香港公众假期生成；香港时间 09:00 为数据截止，目标 10:00 前发布。随后授权接入其 BigModel API，替代依赖本机 Codex 生成的主流程。栏目范围和未接入项保持原约定。

## 时间合同

- 统一时区 Asia/Hong_Kong（UTC+8）。日报日期、截止时间、采集时间、来源统计日期、解读生成时间和完整发布时刻分别保存。
- GitHub Actions 每日 08:37、08:52 提前采集并暂存；09:07 生成解读和 PDF，09:32 自动补查/重试。已发布则直接退出，不再次调用模型。
- 09:00 后采集任务不抓取当前行情补写过去，只复用服务器中截止前的有效数据。服务端再次按实际获取时间及观测时间执行截止检查。
- 九点截止表示系统在九点前已取得的信息集合，并非所有行情恰好 09:00:00 采样。当前快照显示实际时刻；没有符合条件的数据就保留缺口，不倒填。
- 日度和周度解读排除获取时尚未结束的 UTC 日期；仍不代表上游日界线或完整性已经独立确认。周均比较要求连续十四个日历日，不跨越缺日或重复日。
- 每天生成，不因香港假期停采。香港五天工作周口径：周一至周五且非公众假期为工作日。星期六标周末，星期日标公众假期；不据此推断美国股票市场休市。
- 日历来源：[香港政府 1823 免费 JSON](https://www.1823.gov.hk/common/ical/sc.json)。当前覆盖 2025—2027；超出已公布年份显示待更新，禁止推定工作日。

## 模型与费用边界

- 主模型固定 `glm-4.7-flash`，仅调用 `https://open.bigmodel.cn/api/paas/v4/chat/completions`。官方[定价页](https://docs.bigmodel.cn/cn/guide/start/pricing)目前列输入、输出及缓存命中免费；不启用外部搜索、知识库或付费模型回退。
- 用户提供的密钥只保存在 Sites 生产 secret `BIGMODEL_API_KEY`；不进入 GitHub、前端、数据文件、日志或 PDF。网页展示实际生成方和模型，历史 Codex 解读保留原标注。
- 模型只接收已公开数据经程序复算的比较方向、范围和限制；精确金额与变动率直接由网页事实表展示，不让模型重写数字，不接收原始网页指令、账户信息或密钥。不另安装 SDK 或插件。
- 账号限流、服务不可用、格式或证据校验失败时保留上一完整版本。若免费模型停服或计费变化，先由用户决定，不自动升级付费版本。

## 同版发布

1. 免费采集器 → 受 GitHub OIDC 保护的 ingest → 保留有效旧值并执行九点截止 → 暂存快照。
2. `/api/edition?date=YYYY-MM-DD` 返回候选快照、程序事实及哈希。截止前状态 collecting；截止后 awaiting-analysis。
3. `scripts/generate-analysis.py` 经 OIDC 调用服务端 `/api/admin/analysis/generate`；服务端使用密钥请求免费 BigModel，程序设置日期、快照、模型和事实哈希，模型编写观察性文字，业务判断边界由程序按同一事实计算，并自动附齐所依赖的事实引用。
4. 服务器验证四个板块、有效引用、日期、快照、哈希、长度和自由文字中的数字限制，再冻结解读。重试复用完全相同的已冻结解读，不重新生成时间或文字；同时将 PDF 发布归属到当前合法工作流。
5. PDF 从固定快照页面生成，清单绑定 snapshotId + analysisHash；上传成功后，数据库事务统一切换网页、解读和 PDF。任何步骤失败都保留旧版。
6. 下载及预览链接绑定用户当前页面快照。已完整发布的日报不会被重试覆盖。

## 内容合同

每条包含标题、数据解读、业务观察、继续关注和事实引用，覆盖 CEX、DEX、代币化股票及 Hyperliquid。数值、变动率、均值由程序计算，保留数据日期；模型文字不另写数值、排名或无证据原因。单日变化不等于趋势，来源样本不可称全市场，报价币不可混称美元，成交额不可等同净流入、收入或新增用户。Stocks 主题分类不能改写为代币化股票现货总市场；DEX 全市场份额缺口继续说明；Hyperliquid 单次当前快照不推断日度趋势。

服务器可验证数值包、引用及结构一致性，不能证明自然语言的因果解释成立；不宣称人工审定。提示词要求区分观察与有条件推断。未通过验证的内容不进入公开日报。业务观察采用与事实方向对应的明确判断边界，不沿用模型猜测的资金、需求或资产驱动原因。页面已区分模型文字和程序整理的业务边界。

JSON：version=1、producer="BigModel"、model="glm-4.7-flash"、snapshotId、reportDate、factsHash、generatedAt、points。历史 producer="Codex" 仍可读取及验证。每条包含 sector（cex/dex/stocks/hyperliquid）、title、interpretation、implication、watch、factIds；服务器重建 facts，不信任提交的事实文本。

## 运行与恢复

- 主流程由 GitHub Actions 和网站服务端运行，不依赖 Mac 开机或 Codex 在线。GitHub 排队、账号运行限制或来源延迟仍可能使日报迟到；10 点是目标，并非已验证的硬性 SLA。
- 手动 workflow_dispatch 默认 finalize；若没有当日草稿，安全复用截止前存量数据并暂存，再生成报告。
- 创建或更新当天 `data/requests/YYYY-MM-DD.json`（仅 reportDate/requestedAt）可触发恢复：九点前采集，九点后完成整份日报。相同日期仅用同一请求文件，不新增无关内容。
- 原 Codex heartbeat `web3-9-codex` 已调整为 09:10、09:35 运行核查。它不再写分析文件；正常成功和未变化保持安静，仅新故障、需要决定或目标未达时反馈。该额外核查依赖本机在线，云端生成不依赖它。
- 成功条件：`/api/edition` 为 published，且 `/api/data` 与 `/api/reports/latest` 的 reportDate、snapshotId、analysisHash 一致，PDF 有效。触发成功和本地测试不能替代线上验收。
- 源失败保留原日期，不补零；无法持续获取时保留栏目并反馈用户。十点后显示今日延迟。
