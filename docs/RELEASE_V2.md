# v0.2：逐项数据核验与整站 PDF

用户已批准实施。范围为修复原有内容遗漏、逐项登记来源/采集时间/可靠性、按日生成可公开下载的完整报告。未安装数据插件、申请付费数据或更换现有数据源。既有栏目保留，无法满足免费来源/口径条件的项由用户决定。

## 页面和数据

- 新增 `/sources`：49 个基础数据集逐项显示直接获取地址、来源层级、实际采集成功时间、最近尝试、来源刷新时间、数据截至、粒度/单位、缺值、覆盖差额、可靠性依据。登记 UI 额外占位和 27 个仅目录板块，数据集数不作实现率。
- 采集计划继续为北京时间 09:17、13:47（UTC 01:17、05:47）。GitHub 可能排队，计划不保证准点；显示实际时间。新采集日志区别 ok / failed / not-configured，失败时不改旧数据时间。
- 来源时效按当前时间动态检查；日频按源族设置 24/48/72 小时阈值、月频 35 天。数据服务失败回退初始快照时明确标记。首页比较排除当前 UTC 日期，源日界线仍标待核。
- CEX 恢复日/月成交份额、同平台合约/现货比和储备份额。份额排除 ALL/Total，同日分母不完整时留空。原混合平台样本分类不改变，不声称全球 CEX 份额。
- 恢复原有 HL 成交/OI/类别/部署市场构成，RH 钱包/RWA/DEX 构成和7日均线。缺值、负值、重复实体、缺实体或零分母不归一化；7日均线要求连续自然日。
- 修复稳定币按链明细混入币种字段；图、排名和明细采用相同字段集合。逐列单位和中文字段名更清晰。
- 普通专题页只请求相关数据集，完整数据只在总核验/报告需要时加载。

## PDF

- `/report` 使用网站同一 catalog，覆盖总览+12专题、32子标签，以及所有当前恢复的面板。日图固定本批次前90个日历日，月图约24个月且排除当前月；即时快照保留采集时点。
- 阅读正文含所有栏目、默认指标/主要系列图和表格摘要。附录包含7个关键明细数据集的全部已采集行和字段，宽表按字段组拆开、重复记录编号；恒定字段在表头说明，避免重复打印。时序不穷举每个标的/指标筛选组合。28板块和AI等重复空态集中登记。
- Playwright 1.62.1 为批准的开源生成组件，放在 tooling/pdf，通过根 pnpm 锁文件锁定。只在 GitHub 任务和本地生成测试运行，网页客户端不下载 Chromium。
- 先发布并取得服务端 keepLastGood 后的 canonical snapshot；报告按 snapshot ID 读取，不直接用采集候选 JSON。清单验证页面、子标签、面板、图表、28板块都存在。
- R2（Sites 管理的逻辑 REPORTS 绑定）存 PDF 和 JSON 归档，D1 只存元数据。`/api/reports/latest?download=1` 匿名直接下载。私有仓库 artifact 不充当公开下载地址。
- PDF 上传复用 GitHub OIDC 身份校验，audience 绑定报告路由、snapshot ID 和 PDF SHA-256。R2成功后D1事务记录；失败保留上一报告。最新报告按数据批次排序，迟到旧报告不能覆盖新批次。
- D1保留最近60批，只有成功写入归档回执的更旧批次允许清理；未归档版本受保护。归档暂不自动删除，后续容量和保留策略由用户决定。
