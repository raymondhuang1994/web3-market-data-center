# V1 实施说明

2026-09-15。用户已批准 PRD / Spec 并授权直接实现公开网页与 GitHub 项目。本文件记录从设计稿到实际部署的工程选择，数据范围保持批准内容。

## 架构

- 采用 Sites 标准 vinext/React 脚手架与已有 Recharts、shadcn 组件，代替方案中的可选 Vite/ECharts 组合；不影响需求功能。
- 网站部署至 Sites Worker，D1 保存每日有效快照。GitHub Actions 负责采集并调用受保护的 ingest 路由，避免把临时 Sites 源码凭据用作长期 CI 凭据。
- GitHub 私有源码仓库 `raymondhuang1994/web3-market-data-center`；公共网站没有访客登录门槛。
- 每天北京时间 09:17 主更新、13:47 再采集；实际源日期在每张图单独展示。
- 采集为 Python 标准库，可与网站独立维护。没有新增付费 API、订阅或插件。

## 数据状态

49 个采集数据集，初始 16 个 ready、17 个 stale、12 个 review、4 个 pending；这是数据集状态，不能直接等同 PRD 的全部指标实现比例。

额外 UI 占位：资金费率 Z-score、其他币种聚合历史、热门板块除 Stocks 外的 27 类历史。保留全部约定入口；不将占位计作数据接入完成。AI 解读未启用付费生成。

保留原站可读事实数据与来源；未复制原作者文章、AI 原文、品牌资产或主观评分。明确限制再发布的费用数据与 DEX 份额保持空白。原站再分发授权仍非已确认，若来源提出限制需先复核具体数据，不擅自替换栏目。

## 更新与安全

- 所有数据集必须匹配服务器固定 ID、来源 URL 与单位合同。交易所字段可扩展，核心维度不能由上传内容自行省略。
- OIDC 使用固定 GitHub JWKS、RS256、不可变仓库/owner ID、main、精确 workflow_ref、schedule/workflow_dispatch 事件和 private 可见性；新旧官方 subject 格式均受严格独立 ID 校验。
- SHA-256 audience 绑定精确上传字节；jti 唯一键提供持久化幂等保护。不保存 JWT。
- 并发发布通过 snapshot header 的非空约束断言旧 head，再在同一 D1 batch 内写入各数据集和切换 head；失败完整回滚。
- 候选快照采用 UTC canonical 时间。数据日期回退或单源为空时保留上一有效数据；不修改其日期伪装更新。
- 每个 JSON 数据集 <=150 万 UTF-8 字节，插入按 15 行一批，避免 D1 字段与参数上限。
- 迁移 schema-only，运行时没有 DDL；最近三批数据和七天收据有界保存。
